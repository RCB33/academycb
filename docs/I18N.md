# Idiomas de Academy

La web pública y el portal de familias ofrecen castellano (`es`, predeterminado) y catalán (`ca`). El selector ES/CA guarda `academy_locale` durante un año y recarga la URL actual, conservando ruta, parámetros y ancla. El servidor y los componentes interactivos parten del mismo idioma. La administración mantiene su interfaz en castellano.

- Componentes de servidor: `const translate = await getT()` desde `@/lib/i18n/server`.
- Componentes de cliente: `const translate = useT()` desde `@/lib/i18n/client`.
- Catálogo revisado: `src/lib/i18n/ca.json`, con el texto castellano como clave.
- Fechas: `translate.locale` (`es-ES` o `ca-ES`). El calendario usa los locales de date-fns.
- Metadatos públicos: `generateMetadata()` y `translateMetadata()`.

Traducir únicamente la presentación. Mantener los valores de formularios, identificadores, URLs, importes, permisos y registros originales. El catálogo no modifica publicaciones de familias, nombres de jugadores ni documentos originales firmados o descargables. Para textos nuevos publicados desde administración, añadir su equivalencia al catálogo si necesitan traducción; los textos desconocidos conservan su original.

Comprobaciones: `node scripts/test-i18n.cjs`, `npm run typecheck`, `npm run build`. Verificar además ES→CA→ES en la misma ruta, navegación, importes y valores de formulario, calendario y vistas móviles. No enviar solicitudes reales ni iniciar pagos para validar textos.
